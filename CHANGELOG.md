# Changelog

All notable changes to scriptron are listed here. Versions follow [semver](https://semver.org).

## [1.0.0] - 2026-10-11

The first release of scriptron, a screenplay editor for Fountain files on macOS and Windows.

### Added

- Write screenplays in an editor that formats Fountain text as a screenplay page while you type. Files stay plain Fountain text.
- See page breaks, page and scene numbers as they will print, with speeches split across pages using (MORE) and (CONT'D).
- Export to PDF on A4 pages, with the bundled Courier Prime font.
- Press Enter to end a speech, scene heading or action line, and Shift-Enter for a new line within a speech.
- Autocomplete character names, adding (CONT'D) when the same character spoke last, and scene headings: INT./EXT., locations already in the script and times of day.
- Use the toolbar for bold, italic, underline, notes, centered text and page breaks, and autoformat to trim extra spaces and blank lines.
- Browse scenes in a collapsible, searchable sidebar.
- Find and replace with Ctrl/Cmd+F.
- Spellcheck in English and Hungarian, with your own dictionary. Scene headings, character names and notes are left unchecked.
- Open several screenplays in tabs, drag tabs to reorder them, and get your open tabs back when you relaunch.
- Pinch the trackpad to zoom smoothly, or set the interface and screenplay text sizes in Settings.
- Use light, dark or system appearance.
- Open the Big Fish screenplay from File > Open Sample to try the app.
