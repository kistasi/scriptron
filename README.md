# Scriptron

A screenplay editor for [Fountain](https://fountain.io/syntax) files on macOS and Windows. It formats your script as a printed screenplay page while you type, and your files stay plain Fountain text.

- Live page view with page breaks, scene numbers and (MORE)/(CONT'D)
- PDF export on A4 pages
- Autocomplete for character names and scene headings
- Scene outline, find and replace, spellcheck, tabs, light and dark themes

## Download

Get the latest installer from [Releases](https://github.com/kistasi/scriptron/releases). Try it with File > Open Sample.
